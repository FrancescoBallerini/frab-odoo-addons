# Open Records on New Tab

## Overview
This Odoo 14 module enhances list and kanban view functionality by allowing users to open records in a new browser tab using Ctrl+Click, middle-click or Cmd+Click on Mac.

## Features
- **Ctrl+Click** (Windows/Linux) or **Cmd+Click** (Mac) on any list or kanban view record to open it in a new tab
- **Middle-click** (mouse wheel click) on records for the same behavior
- Normal click behavior remains unchanged
- Works on all list and kanban views throughout Odoo
- Preserves the current menu breadcrumb when opening in new tab
